# Universal Recovery Engine (URE)

A cross-platform Java-based file recovery engine supporting FAT32 and NTFS file systems.

## Project Structure

- `src/` - Source code
- `tests/` - Test cases
- `docs/` - Documentation
- `resources/` - Application resources
- `samples/` - Sample/test data
- `scripts/` - Development scripts
- `logs/` - Runtime logs
